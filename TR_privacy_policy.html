Privacy Policy

Talking Ringtones does not collect, store, transmit, or share any personal data.
All features operate entirely on the user’s device, and no information is sent to any server or third party.

Microphone Access (RECORD_AUDIO)

Talking Ringtones uses the microphone only when the user chooses to record a custom audio clip for use as a ringtone.
No audio is recorded automatically, and all recordings remain stored locally on the device.
The app does not upload, share, or transmit any audio.

Contacts Access (READ_CONTACTS)

The app reads the user’s contact names and phone numbers solely so the user can assign a custom ringtone to a selected contact.
No contact information is uploaded, shared, stored externally, or used for any other purpose.
The app does not modify or delete any contact data except updating the ringtone field when the user explicitly requests it.

Modify System Settings (WRITE_SETTINGS)

When the user chooses to set a recorded sound as the device’s default ringtone,
Talking Ringtones requests permission to modify system settings.
This permission is used only for changing the default ringtone and does not change any other settings on the device.

User's Name

When the user wants to send a talking ringtone to some recipient, Talking Ringtones requests user's name.
It is used: (1) to identify the user to the recipient, and (2) to name the ringtone file.
The name is not uploaded, shared, stored externally, or used for any other purpose.

Advertising and Analytics

Talking Ringtones contains no advertising and uses no analytics or tracking of any kind.

Data Sharing

Talking Ringtones does not share any data with any third parties.
No information leaves the user’s device.
